Где живёт клиент

Один и тот же сказочный клиент на трёх платформах. версия 1.0

🍏 macOS

Apple Silicon (M1–M4)macOS 13+.dmg · 17 МБ
⬇️ Скачать для Mac
  1. Открой .dmg и перетащи «Навайбкодил ВПН» на ярлык «Программы».
  2. Запусти из «Программ». Mac скажет, что не может проверить приложение — нажми «Готово».
  3. «Системные настройки» → «Конфиденциальность и безопасность» → внизу «Всё равно открыть» → пароль Mac. Это один раз: у приложения нет платной подписи Apple.
  4. Вставь ключ из бота в «Грамоту», выключи другие VPN и жми «Подключить».

🪟 Windows

Windows 10/11, 64 битустановщик · 79 МБ
⬇️ Скачать для Windows
  1. Запусти NavaibeVPN-Setup.exe. Если Windows покажет синее окно «Система защитила ваш компьютер» — «Подробнее» → «Выполнить в любом случае».
  2. Нажми «Далее» → «Установить». Ярлык появится на рабочем столе.
  3. При запуске Windows спросит права администратора — нажми «Да»: без них весь трафик через VPN не пустить.
  4. Вставь ключ из бота в «Грамоту», выключи другие VPN и жми «Подключить». Крестик сворачивает приложение в трей.

🤖 Android

Android 7+.apk · 49 МБ
⬇️ Скачать для Android
  1. Скачай APK с телефона и открой его из уведомления или «Загрузок».
  2. Если телефон попросит — разреши установку из этого источника (браузера или «Файлов»).
  3. Если Play Защита предупредит о неизвестном приложении — «Подробнее» → «Всё равно установить».
  4. Вставь ключ из бота в «Грамоту» и жми «Подключить». Android спросит разрешение на VPN — «ОК».

Вопросы

Наказ для любопытных

Что это вообще такое?

Собственный клиент, сделанный с нуля для YouTube-видео: на Mac оболочка на Swift, на Windows — на C#, на Android — на Kotlin, а внутри везде официальное ядро Xray-core. Подключается к нашему серверу VLESS + Reality.

Это платно?

Нет. Проект некоммерческий, тарифы на сайте и в боте — просто декорации для видео.

Где взять ключ?

В Telegram-боте @navaibevpn_bot. Сейчас бот работает в режиме показа для видео, и новые ключи могут не выдаваться.

Почему macOS не даёт открыть приложение?

У приложения нет платной подписи Apple. Открой «Системные настройки» → «Конфиденциальность и безопасность» и нажми «Всё равно открыть». Это нужно сделать один раз.

Windows пишет «Система защитила ваш компьютер»

Так Windows встречает программы без платной цифровой подписи. Нажми «Подробнее» → «Выполнить в любом случае». Права администратора приложению нужны, чтобы создать сетевой адаптер VPN.

Android не даёт установить APK

Разреши установку из источника, откуда открываешь файл (браузер или «Файлы»), а на предупреждение Play Защиты нажми «Подробнее» → «Всё равно установить». Приложения нет в Google Play, поэтому так.

Зачем приложение просит пароль Mac?

Чтобы пустить через VPN весь трафик, нужно создать сетевой интерфейс и поменять маршруты. Это может только администратор. Пароль спрашивается один раз: приложение ставит маленького помощника, который умеет только включать и выключать VPN.

Можно вместе с Happ или другим VPN?

Нет: два VPN спорят за маршруты. Перед подключением выключи другой VPN, клиент сам подскажет, если что-то мешает.

А для iPhone будет?

Терем строится. Для iPhone нужно отдельное приложение и платный аккаунт разработчика Apple.
